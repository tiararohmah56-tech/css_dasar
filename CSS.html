Modul 1

Fondasi CSS (Pengenalan & Sintaks)

1. Apa itu CSS?

Jika HTML adalah struktur & tulang dari sebuah rumah, maka CSS adalah cat, dekorasi, furnitur, dan tata letak yang membuat rumah tersebut indah dipandang dan nyaman dihuni.

2. Tiga Cara Menghubungkan CSS ke HTML

a. Inline CSS (Langsung di Tag HTML)

<h1 style="color: blue; text-align: center;">Halo Dunia!</h1>

Catatan Guru: Kurang disarankan untuk proyek besar karena membuat HTML berantakan.

b. Internal CSS (Di dalam tag <style>)

<head>
  <style>
    h1 {
      color: blue;
      text-align: center;
    }
  </style>
</head>

c. External CSS (File Terpisah - Sangat Direkomendasikan)

// index.html <head>
 <link rel="stylesheet" href="style.css">
</head>
/* style.css */ h1 {
  color: #2c3e50;
  text-align: center;
}

3. Anatomi Sintaks & Selector CSS

/* Selector { Property: Value; } */
p {
  color: red; /* Mengubah warna teks */
  font-size: 16px; /* Mengubah ukuran font */
}

Element Selector

Target langsung nama tag (misal: h1, p, div).

Class Selector (.)

Target elemen dengan class tertentu (misal: .btn-primary). Dapat dipakai berulang.

ID Selector (#)

Target elemen unik dengan ID (misal: #header-main). Hanya untuk 1 elemen.

Modul 2

Pewarnaan, Tipografi, & Box Model

Format Warna CSS

  • Nama Warna: red, teal
  • HEX Code: #FF5733
  • RGBA (Transparan): rgba(79,70,229,0.8)

Tipografi Modern

Penggunaan Google Fonts untuk tampilan profesional: 

@import url('https://fonts.googleapis.com/...');

body {
  font-family: 'Poppins', sans-serif;
  line-height: 1.6;
}

Konsep CSS Box Model (Sangat Penting! ⚠️)

MARGIN (Ruang Luar)
BORDER (Garis Tepi)
PADDING (Ruang Dalam)
CONTENT (Teks/Gambar)
1. Content

Teks, gambar, atau konten utama di dalam elemen.

2. Padding

Ruang kosong di antara Content dan Border.

3. Border

Garis pembatas tepi di sekeliling padding.

4. Margin

Jarak ruang kosong luar dengan elemen tetangga.

Trik Emas Box-Sizing

* { box-sizing: border-box; margin: 0; padding: 0; }

Penggunaan border-box memastikan ukuran total elemen tidak membengkak saat diberi padding dan border.

Modul 3

Tata Letak Modern (Flexbox & Grid)

CSS Flexbox

1 Dimensi

Sangat cocok untuk komponen satu baris/kolom seperti navigasi, deretan kartu, atau penyelarasan di tengah. 

.container {
  display: flex;
  justify-content: center;
  align-items: center;
  gap: 20px;
}

Modul 4

Desain Responsif & Interaktivitas

1. Media Queries (Web Responsif Mobile)

Media Queries memungkinkan kita mengubah gaya tampilan berdasarkan ukuran layar perangkat pengguna (Smartphone vs Desktop). 

/* Desktop Default */
.card-container { display: flex; }

/* Mobile Screen (Lebar <= 768px) */
@media (max-width: 768px) {
  .card-container {
    flex-direction: column;
  }
}

2. Transisi & Efek Hover

Efek transisi memberikan kehalusan animasi saat pengguna berinteraksi dengan elemen. 

.btn {
  background-color: #3498db;
  transition: all 0.3s ease;
}

.btn:hover {
  background-color: #2980b9;
  transform: translateY(-3px);
}
