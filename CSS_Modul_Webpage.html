Selector & Properti Dasar

Selector adalah cara kita "memilih" elemen HTML yang ingin diberi gaya. Coba praktikkan langsung di editor di bawah ini. Ubah kode CSS di sebelah kiri dan lihat hasilnya secara langsung di sebelah kanan. Ikuti petunjuk di dalam komentar untuk memulai.

Memahami Box Model

Setiap elemen di web adalah sebuah "kotak". Box Model adalah aturan yang mendefinisikan ruang di sekitar elemen. Gunakan slider di bawah untuk melihat bagaimana `padding`, `border`, dan `margin` memengaruhi sebuah elemen secara visual.
